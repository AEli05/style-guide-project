# Пример: описание витрины dm.ab_conversion_daily

Документ написан по шаблону из раздела [Типы документов и шаблоны](../doc-types.md). Данные учебные.

## Назначение

Витрина нужна для расчета конверсии в заявку в A/B-тестах экранов приложения. Ей пользуются аналитики продукта и дашборд «A/B-тесты: конверсия».

## Источники

- `dm.ab_assignments` - распределение пользователей по группам тестов;
- `dm.app_events` - события приложения.

## Гранулярность

Одна строка - один пользователь в одном тесте за один день.

## Поля

| Поле | Тип | Описание |
| --- | --- | --- |
| `event_date` | date | Дата, ГГГГ-ММ-ДД |
| `test_id` | varchar | Идентификатор теста |
| `ab_group` | varchar | `control` или `test` |
| `user_id` | bigint | Обезличенный идентификатор пользователя |
| `screen_opened` | int | 1, если пользователь открыл экран продукта в этот день |
| `application_submitted` | int | 1, если пользователь отправил заявку в этот день |

Конверсия в заявку за период считается по уникальным пользователям: число пользователей с `application_submitted = 1` делим на число пользователей с `screen_opened = 1`.

## Обновление

Ежедневно, данные за вчера готовы к 09:00 по Москве.

## Особенности данных

- Тестовые аккаунты и сотрудники исключены на этапе сборки.
- Пользователь учитывается один раз за день, даже если отправил несколько заявок.

!!! warning "Досчет данных"
    События за последние 2 дня могут доезжать с задержкой. Для отчетов берем период, который закончился не меньше 3 дней назад.

## Пример запроса

Конверсия в заявку по группам теста за сентябрь:

```sql
SELECT
    ab_group,
    COUNT(DISTINCT CASE WHEN application_submitted = 1 THEN user_id END) * 1.0
        / COUNT(DISTINCT CASE WHEN screen_opened = 1 THEN user_id END) AS conversion
FROM dm.ab_conversion_daily
WHERE test_id = 'new_application_screen'
  AND event_date BETWEEN '2026-09-01' AND '2026-09-30'
GROUP BY ab_group;
```

Результат: по одной строке на группу, конверсия в долях.
