# Пример: отчет по A/B-тесту нового экрана заявки

Данные в примере учебные.

## Вывод

Новый экран заявки увеличил [конверсию в заявку](datamart.md) на 0,70 п.п.: с 6,10% до 6,80% (+11,5% относительно контрольной группы). Разница статистически значима. Рекомендуем внедрить новый экран на всех пользователей.

## Гипотеза

Если сократить форму заявки с 9 полей до 5 и подтянуть данные из профиля, больше пользователей дойдет до отправки заявки.

## Дизайн теста

| Параметр | Значение |
| --- | --- |
| Период | 01.09.2026-30.09.2026 |
| Группы | 50% контрольная, 50% тестовая |
| Целевая метрика | конверсия в заявку |
| Контрольная метрика | доля одобренных заявок |
| Тест | z-тест для долей, α = 0,05 |
| MDE | 0,5 п.п. при мощности 80% |
| Дата выгрузки данных | 05.10.2026 |

## Результаты

| Группа | Пользователей | Заявок | Конверсия в заявку, % |
| --- | ---: | ---: | ---: |
| Контрольная | 24 812 | 1 514 | 6,10 |
| Тестовая | 24 655 | 1 677 | 6,80 |

Разница: +0,70 п.п., 95% доверительный интервал [0,27; 1,13] п.п., p = 0,002.

Доля одобренных заявок в группах не отличается статистически значимо, то есть новый экран не привел больше нецелевых заявок.

## Ограничения

- В тест попали только пользователи версии приложения 5.2 и выше, это около 80% аудитории.
- В середине сентября шла рекламная кампания продукта. Она действовала на обе группы одинаково, но могла поменять состав пользователей, которые открывали экран.

## Рекомендация

Внедрить новый экран заявки на всех пользователей. Через месяц после внедрения сверить конверсию в заявку с результатом теста.
