# Орфография и пунктуация

## Буква е

Вместо буквы `ё` пишем е: «еще», «учет», «отчет». Исключение - слова, где без нее меняется смысл, но в аналитических текстах они почти не встречаются. Правило проверяет линтер.

## Дефис и тире

Используем только обычный дефис `-`. Длинное и среднее тире не используем: их сложно набрать, а в коде и в Markdown они выглядят по-разному.

- Между словами - дефис с пробелами: «конверсия - это доля пользователей...».
- В диапазонах - дефис без пробелов: «10-15%», «01.09.2026-30.09.2026».

## Кавычки

- В русском тексте - «елочки».
- Внутри кода, в названиях полей и в JSON - прямые кавычки `"`.
- Типографские кавычки `“ ”` и `„ “` не используем.

## Сокращения

- Общепринятые сокращения пишем без расшифровки: млн, тыс., руб., т.д.
- Процентный пункт пишем как п.п.
- Специальные аббревиатуры (MDE, CI, DAU) при первом упоминании расшифровываем: «минимальный детектируемый эффект (MDE)».

## Иноязычные слова

- Названия инструментов пишем как в оригинале: Python, SQL, MkDocs, Power BI.
- Если есть устоявшийся русский термин, используем его: «выборка», а не «сэмпл».
- Сленг вроде «раскатить» допустим в рекомендациях, если его понимает заказчик. В формальных отчетах для руководства пишем «внедрить на всех пользователей».
