# Глоссарий

Утвержденные названия. Если термина нет в таблице, его добавляют через Pull Request.

## Метрики

| Используем | Не используем | Определение |
| --- | --- | --- |
| конверсия в заявку | CR, доля заявок, конверт | Доля пользователей, отправивших заявку, среди всех пользователей группы |
| активный клиент | живой клиент, актив | Клиент, совершивший хотя бы одну операцию за последние 30 дней |
| средний чек | AOV, средняя покупка | Сумма операций, деленная на число операций |
| удержание 30 дня | ретеншн, retention | Доля пользователей, вернувшихся на 30 день после первого входа |
| инкрементальный эффект | аплифт, прирост | Разница метрики между тестом и контролем, вызванная воздействием |

## Термины экспериментов

| Используем | Не используем | Определение |
| --- | --- | --- |
| тестовая группа | тест, экспериментальная | Группа, которая видит изменение |
| контрольная группа | контроль, база | Группа без изменения |
| уровень значимости, α | альфа-уровень | Допустимая вероятность ложноположительного результата |
| минимальный детектируемый эффект (MDE) | минимальный эффект | Наименьший эффект, который тест способен обнаружить при заданной мощности |
| доверительный интервал | CI, вилка | Диапазон, в котором с заданной вероятностью лежит истинный эффект |

## Запрещенные обороты

Эти слова и обороты проверяет скрипт `scripts/check_style.py`:

| Не пишем | Пишем |
| --- | --- |
| `в ходе` анализа | при анализе, когда считали |
| `было установлено` | мы обнаружили |
| `следует отметить` | (просто пишем факт) |
| `осуществлять` | делать, проводить |
| `данный` отчет | этот отчет |
| `в рамках` теста | в тесте |
